03

选择公网连接方式

固定地址由你的服务器提供，重启后沿用同一个 MCP 地址

本机专用 SSH 公钥只允许服务器反向转发；私钥留在本机用户目录

服务器需允许 SSH 反向转发，并由 Nginx / Caddy 将 HTTPS 请求转发到 127.0.0.1:43128。固定 IP 可使用自动续期证书；服务器部署说明见随包 README。

保存后首次部署时，将公钥加入服务器的 localmcp 用户。
创建临时 HTTPS 隧道，不需要配置域名
04

连接到 ChatGPT

复制 MCP 地址，在 ChatGPT 中添加自定义应用

打开 ChatGPT
地址含访问令牌，请勿公开分享。自有服务器模式下地址固定；断开时服务暂不可用，重连后恢复。
需要撤销旧地址时可轮换令牌；重置后 ChatGPT 中的旧连接将失效。
  1. 在设置中开启开发者模式（可用性取决于账号方案和工作区策略）。
  2. 进入 Apps / Plugins，选择创建自定义 MCP 应用。
  3. 粘贴完整地址并扫描工具，再按需要启用权限。
  4. 在新对话中选择该应用即可开始使用。
