# Self-hosted HTTPS ingress

This folder contains generic server configuration templates. Local MCP tools run on the user's Windows computer; the server provides HTTPS and forwards requests through a restricted SSH reverse tunnel. The server does not contain a copy of the user's project or MCP token.

## Requirements

- A Linux server with a public address and a DNS name such as `mcp.example.com` pointing to it.
- SSH, Nginx, and Certbot.
- Inbound TCP ports 22, 80, and 443. The reverse-forward port `43128` must stay private on loopback.
- A trusted client public key, generated by Local MCP Studio after the user saves their own server settings.

The templates target a Debian or Ubuntu style Nginx/Certbot installation. They are examples to review for the server's existing SSH, firewall, and Nginx layout.

## Configure the restricted SSH account

Create a dedicated account and an empty authorized-keys file:

```bash
sudo adduser --disabled-password --gecos "" localmcp
sudo install -d -m 700 -o localmcp -g localmcp /home/localmcp/.ssh
sudo install -m 600 -o localmcp -g localmcp /dev/null /home/localmcp/.ssh/authorized_keys
```

Append `sshd-match-localmcp.conf` to the end of `/etc/ssh/sshd_config`. Then check and reload SSH:

```bash
sudo sshd -t
sudo systemctl reload ssh || sudo systemctl reload sshd
```

In the client's server settings, generate or display its public key. Add it to `/home/localmcp/.ssh/authorized_keys` with these per-key restrictions:

```text
restrict,port-forwarding,command="/bin/false" ssh-ed25519 AAAA... Local MCP Studio
```

Keep the client's private key on the client. Confirm the server SSH host fingerprint in the client before saving the settings. The configured reverse-forward port must remain bound to `127.0.0.1`; do not open port `43128` in the firewall.

## Configure HTTPS for one hostname

Set a DNS A record for the hostname to this server. Create the ACME webroot and install the temporary HTTP-only config:

```bash
sudo mkdir -p /var/www/localmcp-acme
sudo cp nginx-acme-bootstrap.conf /etc/nginx/sites-available/local-mcp-studio
sudo sed -i 's/YOUR_MCP_DOMAIN/mcp.example.com/g' /etc/nginx/sites-available/local-mcp-studio
sudo ln -s /etc/nginx/sites-available/local-mcp-studio /etc/nginx/sites-enabled/local-mcp-studio
sudo nginx -t && sudo systemctl reload nginx
```

Issue a certificate using an email address controlled by the server owner:

```bash
sudo certbot certonly --webroot -w /var/www/localmcp-acme \
  -d mcp.example.com --agree-tos -m admin@example.com --non-interactive
```

Replace `YOUR_MCP_DOMAIN` in `nginx-local-mcp.conf` with the hostname and copy it over the temporary config. Validate and reload Nginx:

```bash
sudo cp nginx-local-mcp.conf /etc/nginx/sites-available/local-mcp-studio
sudo sed -i 's/YOUR_MCP_DOMAIN/mcp.example.com/g' /etc/nginx/sites-available/local-mcp-studio
sudo nginx -t && sudo systemctl reload nginx
```

The Nginx configuration matches only the selected hostname, serves only `/mcp/`, and disables access logs because the MCP bearer token is part of the URL. It proxies to `127.0.0.1:43128`, where the SSH reverse tunnel listens. It does not alter other virtual hosts.

Certbot's systemd timer can renew certificates automatically. If the server does not use that timer, install `renew-cert.sh` and schedule it with the server's normal scheduler. The deploy hook reloads Nginx only after Certbot renews a certificate.

## Configure Local MCP Studio

In **自有服务器固定地址**, enter the server SSH hostname, port, dedicated SSH user, and the HTTPS origin (for example `https://mcp.example.com`). Use **读取指纹** and compare it with the fingerprint obtained from the server console. Save the settings, select a project and permission level, then start the connection. The client generates and stores its own MCP token locally; no token is required in the server configuration.

The server has no separate MCP application source: the MCP service runs with the client on the user's computer. `src/main.js` is the bridge source; the files in this directory provide the user's own HTTPS and SSH ingress.
